# Laporan Praktik Demonstrasi Aplikasi BookStore

## Identitas Aplikasi

Nama aplikasi: BookNest BookStore

Deskripsi: Aplikasi toko buku berbasis web full-stack yang menyediakan fitur admin untuk mengontrol data buku dan fitur user untuk mencari serta memesan buku. Data aplikasi tersimpan di database PostgreSQL.

## Fitur Admin

- Add, update, delete kategori buku.
- Add, update, delete data buku.
- Melihat daftar user yang sudah terdaftar.
- Melihat daftar pesanan buku dari user yang berbeda.
- Mengubah status pengiriman pesanan.
- Melihat pesan kontak dari user.

## Fitur User

- Registrasi user.
- Login user.
- Melihat halaman About Us.
- Mengirim pesan ke admin.
- Pencarian buku.
- Add to cart buku.
- Checkout dengan Payment at Delivery.
- Melihat status pengiriman buku pada menu Pesanan Saya.

## Teknologi dan Library

- HTML5 untuk struktur aplikasi.
- CSS3 untuk styling responsif.
- JavaScript untuk pemrograman terstruktur.
- Node.js dan Express.js untuk backend API.
- PostgreSQL sebagai database.
- Bootstrap 5 sebagai library UI pre-existing.
- Bootstrap Icons sebagai library ikon.

## Organisasi File

- `index.html`: halaman utama aplikasi.
- `styles.css`: file style aplikasi.
- `app.js`: fungsi frontend dan pemanggilan API.
- `server.js`: backend API, tabel database, dan seed data awal.
- `package.json`: dependency dan script aplikasi.
- `.env`: konfigurasi koneksi PostgreSQL.
- `.env.example`: contoh konfigurasi environment.
- `mockup.html`: rancangan/wireframe sederhana aplikasi.
- `README.md`: petunjuk menjalankan aplikasi.
